# GoalMuse — 5-minute demo script

Use this for a judge-ready demo. Target: **~5 minutes**. App should speak for itself.

## Before you start

- Backend on port 8000 (optional; use **demo@goalmuse.app** / **demo123** for mock login if not).
- Frontend: `npx expo start`; device or simulator ready.

## Minute 0–1: Sign in

1. Open app → Login.
2. Enter **demo@goalmuse.app** / **demo123**. Tap **Log in**.
3. Land on Board tab.

## Minute 1–2: Board and goals

1. Create board if none; tap **Add goal**. Add 2–3 goals (e.g. "Ship feature X", "Run 5K").
2. Show Board tab (goal grid) and Goals tab (list).

## Minute 2–3: Tasks and journal

1. **Tasks & Journal** tab. Add 2–3 tasks; complete one or two. Add one journal entry.
2. Optional: link a task to a goal.

## Minute 3–4: Insights and AI

1. Open **Insights**. Show: Progress confidence (score + "How it's calculated"), Task completion, By goal, Alignment, Synergy, **Next action** (one suggestion + reason).
2. Tap **Did this help?** → Yes. Show "Thanks for your feedback."

## Minute 4–5: Account

1. Tap Account (user icon on Board). Show email; tap **Log out**. Back at Login.

## If something breaks

- API error on Insights: show error state, tap **Try again**.
- No backend: use mock login; UI and navigation still work.

## Closing

"GoalMuse: vision board, goals, tasks, journal, and AI that gives one next action with a reason—plus Opik so improvements are measurable."

---

## Demo flow summary

1. **Login** → 2. **Board + goals** → 3. **Tasks & journal** → 4. **Insights** (confidence, alignment, synergy, next action, feedback) → 5. **Account / Log out**.

No explanation required; judges understand value in under 60 seconds. App is calm, intentional, and credible.
